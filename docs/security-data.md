# This repo contains the details for a given security

The manifest is located under https://github.com/vizfolio/securities-extracts/blob/main/by_ticker.json, which contains a mapping of a ticker to a CIK.

The details of that ticker/CIK are under by_cik/{cik}.json. The schema for the details is located under https://github.com/vizfolio/securities-extracts/blob/main/schemas/security.json.
